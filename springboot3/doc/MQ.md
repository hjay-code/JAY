1. Kafka
1.1. 核心原理
1.1.1. 分区：海量数据分散在不同的机器
1.1.2. 副本：每个数据区在其他机器的备份
1.2. 消费者可以分组
1.2.1. 同一个组里面的消费者是队列竞争模式
1.2.2. 不同组的消费者是 发布/订阅 模式
1.2.3. 一个 消费者 可以消费 多个 分区 的数据
1.3. KafkaController 实现类
1.3.1. 发送实体类时，需要设置系列化器，默认序列化器是 StringSerializer
1.3.2. key 和 value 都可以指定序列化器，也可以手动转成字符串，如实体类手动转化成json字符串
1.4. MqConfigKafka 中可以配置默认的主题 topic1
1.4.1. 老版本的依赖包可能需要在启动类添加 EnableKafka 注解
1.5. 自定义 kafka 监听器 MyTopicListener
1.5.1. 使用 KafkaListener 方法注解来监听对应的主题消息
1.5.1.1. Stirng 类型的参数 只获取了主题消息的内容
1.5.1.2. ConsumerRecord 类型的参数 获取了主题消息本身
1.5.1.3. 默认只能拿到新消息
1.5.2. 需要指定消费者组，可以在 KafkaListener 方法注解指定，也可以在配置文件指定
